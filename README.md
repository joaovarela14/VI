# Remote Work & Mental Health Visualization

This project is an interactive data visualization developed for the **Information Visualization** course (University of Aveiro, 2025/26).  
It explores the relationship between **remote work** and **mental health indicators** such as stress, productivity, satisfaction, and social isolation.

Using **D3.js**, the app allows users to visually explore patterns and correlations between work conditions and psychological well-being.  
It follows a **human-centred design** process, going from low-fidelity prototypes to a refined interactive version, and includes multiple coordinated visual views (scatter plot, bar chart, radar chart, etc.).

### Main Goals
- Analyse how different work arrangements (remote, hybrid, on-site) affect stress and satisfaction levels.  
- Identify patterns related to workload, virtual meetings, and access to mental-health resources.  
- Provide clear and engaging visual representations that support exploratory data analysis.

### Tools and Technologies
- **D3.js** for interactive visualizations  
- **React** for the interface  
- **CSV dataset** from public sources  
[Link to the dataset](https://www.kaggle.com/datasets/iramshahzadi9/remote-work-and-mental-health)


## How to run 
```bash
cd remote-mental-health-viz
npm i
npm run dev
```
